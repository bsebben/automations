# Automations

Personal automation tools for macOS.

## Tools

### [screenshot-tool](screenshot-tool/)

ShareX-style screenshot and screen recording tool. Highlights windows/elements on hover, supports region selection, Shottr annotation, and GIF recording. Triggered via Alfred hotkey.

```bash
./screenshot-tool/screenshot-annotate.sh              # Screenshot
./screenshot-tool/screenshot-annotate.sh --annotate    # With annotation
./screenshot-tool/screenshot-annotate.sh --record      # Record to GIF
```
